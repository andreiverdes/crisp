# Website

Static, no build step. Deployed to GitHub Pages from this directory by `.github/workflows/pages.yml`.

- `index.html`: homepage, React + HorizonUI from `vendor/` (same bundle the benchmark inlines). No build step.
- `benchmark/index.html`: the 3-tab benchmark dashboard, generated by `python3 site/build_data.py && python3 site/build.py` (self-contained, HorizonUI inlined).
- `hero-banner.png`, `twitter-card.png`: README and social images. `hero-*.svg`: the SKILL.md banner, generated by `python3 site/hero.py`.

Preview: `cd web && python3 -m http.server 8765`.
